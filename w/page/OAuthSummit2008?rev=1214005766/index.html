Event details

 

June 26, 11am-6pm

 

Hosted by Yahoo!

2821 Mission College Blvd

Santa Clara, California 95054

 

Upcoming Link

 

Important: This Summit is intended for a highly technical audience of OAuth implementors and will address recent topics and extensions. It will not offer an introduction to OAuth. If you sign up, you are expected to be well versed with the specification and it is recommended that you have already written and/or deployed OAuth services.

 

 

Agenda

 

DRAFT SUMMIT AGENDA

If you have suggested changes/additions to this agenda, please let us know. In particular, if you have demos, announcements, or major discussion topics you would like to see added, please send us mail and we'll try to include them.

 

  • 11am-Noon: OAuth update - IPR status, OAuth core, general announcements, new proposal summary [coordinator: Eran Hammer-Lahav eran@hueniverse.com]
  • Noon-1pm: Lunch
  • 1pm-1:30pm: Demos & Vote on Sessions [coordinator: Eric Sachs esachs@google.com]
  • 1:30-6pm: Sessions
  • 6pm: Drinks/snacks

 

Potential session topics include:

  • Discussion of "1.1" scope (but not details of individual items) [coordinator: Eran Hammer-Lahav eran@hueniverse.com]
  • Error Handling (if agreed to be in 1.1 scope) [coordinator: Eran Hammer-Lahav eran@hueniverse.com]
  • Token Attributes (if agreed to be in 1.1 scope) [coordinator: Eran Hammer-Lahav eran@hueniverse.com]
  • OAuth+XRDS Discovery [coordinator: Eran Hammer-Lahav eran@hueniverse.com]
  • OAuth+OpenSocial [presenter: John Panzer jpanzer@acm.org]
  • OAuth+OpenID [coordinator: Eric Sachs esachs@google.com]
  • Extensions for large service providers [coordinator: Eran Hammer-Lahav eran@hueniverse.com]
  • OAuth+Gadgets [coordinator: Eric Sachs esachs@google.com]

If you have other suggested sessions, please let us know. If you would like to help with coordination/presentation of any of these topics, contact the person above.

 

There is one large room and two smaller rooms available for the summit. If possible, we would like to avoid splitting off into the smaller rooms unless it becomes necssary.

 

 

Organizers
